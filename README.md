A major overhaul of the system in the (private) repo odin-jrpg. Instead of scripts running from a list of unioned structs, we now have a threading system that allows us to write scripts in native Odin. Features from the old repo are being reintroduced into the new system incrementally, with Claude assisting in refactoring.

Content is all just to demonstrate the features. This repo can be forked and content added to make a real game.
