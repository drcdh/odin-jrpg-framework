A major overhaul of the system in the (private) repo [odin-jrpg](https://github.com/drcdh/odin-jrpg). Instead of scripts running from a list of union-ed structs, we now have a threading system that allows us to write scripts in native Odin. Features from the old repo are being reintroduced into the new system incrementally, with Claude assisting in refactoring.

Content in this repo is just to demonstrate the features. This repo can be forked and content added to make a real game.
